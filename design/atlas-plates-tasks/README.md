## 用法
- 每个任务一个 txt，内含英文版 + 中文版两套完整提示词，整段复制即可用
- `tasks.json` 是同内容的机器可读格式（批量任务工具可直接导入）
- 先做 01 定调，满意后用垫图 / `--sref` 锁风格批量出其余

## 硬性约束
1. 图内不得出现任何文字、字母、数字、logo（厂商名由前端代码叠加）
2. 祖母绿只能出现一处点缀，白金线 + 香槟纸是主体
3. 哑光铜版画质感；拒绝 3D 渲染、光泽、彩色海报背景
4. 封底中心圆徽章必须留空（Atlas 字标由代码叠加在圆心）
